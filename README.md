# Museum Lorem Web Application

## Overview
The **Museum Lorem Web Application** is designed to streamline and enhance the management of a museum's operations, exhibitions, and guided tours. This platform provides various features tailored to different user roles, ensuring efficient management and an engaging experience for visitors.

---

## Features

### General Features
- **View Exhibitions and Tours**: All users, including unregistered visitors, can view:
  - Upcoming exhibitions.
  - Guided tours.
  - Museum halls and permanent displays.
- **Staff Directory**: A dedicated page lists all museum staff members.

### Role-Specific Features

#### **Admin**
- Create and manage exhibitions, guided tours, and exhibits.
- Assign existing tour guides to exhibitions and tours.
- View and manage all bookings made by visitors.

#### **Tour Guide**
- Access a personalized schedule of assigned tours and exhibitions.
- View details, including dates and times, of assigned activities.

#### **Visitor**
- Browse exhibitions, tours, and halls.
- **Logged-in Visitors**:
  - Book tickets for tours and exhibitions.
  - Securely pay for bookings.

#### **Unregistered Users**
- View information about exhibitions, tours, halls, and museum staff.
- Booking and payment functionalities are restricted.

---

## Technologies Used

- **Frontend**: HTML/CSS/JS
- **Backend**: Django
- **Database**: SQLite

---

## Usage

- **Admin users**: Log in and access the admin panel to manage museum operations.
- **Tour guides**: Log in to view their assigned schedules.
- **Visitors**: Create an account to book and pay for tickets.
- **Unregistered users**: Browse general information about the museum.
